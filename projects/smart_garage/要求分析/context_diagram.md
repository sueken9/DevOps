# スマートガレージ コンテキストダイアグラム

## システム名

スマートガレージ制御システム

## コンテキストダイアグラム

```mermaid
flowchart LR
    interlock[インターロックスイッチ] -->|操作許可有無| system
    open_close_btn[開閉ボタン] -->|開閉操作| system
    emergency_btn[緊急停止ボタン] -->|緊急停止有無| system
    ultrasonic[超音波センサー] -->|物体距離| system

    system((スマートガレージ\n制御システム))

    system -->|開閉指示| motor[ガレージモータ]
    system -->|点灯指示| led[LED]
    system -->|鳴動指示| buzzer[ブザー]
```

## 外部エンティティ一覧

| 外部エンティティ | 種別 | データフロー（方向） | データ名 |
|----------------|------|-------------------|---------|
| インターロックスイッチ | H/W（入力） | → システム | 操作許可有無 |
| 開閉ボタン | H/W（入力） | → システム | 開閉操作 |
| 緊急停止ボタン | H/W（入力） | → システム | 緊急停止有無 |
| 超音波センサー | H/W（入力） | → システム | 物体距離 |
| ガレージモータ | H/W（出力） | システム → | 開閉指示 |
| LED | H/W（出力） | システム → | 点灯指示 |
| ブザー | H/W（出力） | システム → | 鳴動指示 |
