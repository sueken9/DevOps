# スマートガレージ データ辞書

## データ一覧

| 論理名 | 値域定義 | 説明 |
|--------|---------|------|
| 操作許可有無 | ＝ [ ロック \| リリース ] | インターロックスイッチの状態。ロックのとき開閉ボタンは無効 |
| ロック装置状態 | ＝ [ ロック状態 \| アンロック状態 ] | D2データストアに保持するロック装置の現在状態 |
| 開閉操作 | ＝ [ 開操作 \| 閉操作 \| 一時停止 ] | 開閉ボタンの押下内容 |
| 開閉モード | ＝ [ オープンモード \| クローズモード \| ストップモード ] | 開閉操作を内部表現に変換したデータ。ボタン押下ごとに生成されP4へ流れる（データストアではない） |
| 緊急停止操作 | ＝ [ 操作あり \| 操作なし ] | 緊急停止ボタンの押下状態（外部入力） |
| 緊急停止有無 | ＝ [ 通常作動 \| 緊急停止 ] | 緊急停止を検知するの出力。ボタン操作または物体検知に基づく緊急停止の有無 |
| 物体距離 | ＝ 0以上の実数値 /* 単位：cm */ | 超音波センサーが計測した最近接物体までの距離 |
| ガレージ作業指示 | ＝ [ 上昇指示 \| 下降指示 \| 停止指示 ] | 判断系から扉制御プロセスへの内部作業指示 |
| 開閉指示 | ＝ [ 開指示 \| 閉指示 \| 停止指示 ] | ガレージモータへの動作指示 |
| 点灯指示 | ＝ 表示色 ＋ 点灯パターン | LEDの点灯状態指示 |
| 表示色 | ＝ [ 赤色 \| 緑色 \| 青色 ] | LEDの表示色 |
| 点灯パターン | ＝ [ 消灯 \| 点滅 \| 連続 ] | LEDの点灯パターン |
| 鳴動指示 | ＝ [ 受付音 \| 警告音 \| メロディ ] | ブザーの鳴動内容指示 |
| 扉状態 | ＝ 扉動作状態 ＋ 扉停止理由 | D1データストアに保持する扉の現在状態 |
| 扉動作状態 | ＝ [ 上昇中 \| 下降中 \| 停止中 ] | 扉が動いているかどうか、および方向 |
| 扉停止理由 | ＝ [ 通常 \| 一時停止 \| 物体検知 \| 緊急ボタン ] | 停止中のときの理由。再開条件の判断に使用 |
