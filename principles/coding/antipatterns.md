# アンチパターン

## 目的が違う処理を1行にまとめる

目的が異なる処理は、必ず別の行に分けて書く。メソッドチェーンで繋いで1行にしない。

### 例：生成と実行を繋げる

```csharp
// ✗ 悪い：生成と実行が1行に混在している
SmartGarageFactory.Create().Run();

// ○ 良い：目的ごとに行を分ける
var controller = SmartGarageFactory.Create();  // 生成
controller.Run();                              // 実行
```

### なぜ分けるか

| 処理 | 目的 |
|------|------|
| `Create()` | オブジェクトの生成・組み立て |
| `Run()` | 処理の実行・開始 |

目的が違う処理を1行に詰め込むと：
- 何をしている行かが読み取れない
- デバッグ時にどちらで問題が起きたか特定しにくい
- 変数に名前がつかないため、何が生成されたか不明になる

### 判断基準

「この行は何をしているか」を1語で答えられない場合は、行を分ける。
